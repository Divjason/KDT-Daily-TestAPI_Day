02. 주관식 모범답안 · Q41~Q50

Q41 · 모범답안

DDL = Data Definition Language(데이터 정의어): CREATE, ALTER, DROP 등으로 구조를 정의합니다.
DML = Data Manipulation Language(데이터 조작어): SELECT, INSERT, UPDATE, DELETE 등으로 데이터를 조작합니다.
DCL = Data Control Language(데이터 제어어): GRANT, REVOKE 등으로 권한을 제어합니다.
TCL = Transaction Control Language(트랜잭션 제어어): COMMIT, ROLLBACK 등으로 Transaction을 제어합니다.

Q42 · 모범답안

products 테이블에서 가격이 150,000원 이상인 상품의 상품명과 가격을 조회하고, 가격이 높은 순서로 정렬합니다. 조회 결과에서는 각각 상품명, 가격이라는 Alias로 표시합니다. 

SELECT
    product_name AS 상품명,
    price AS 가격
FROM products
WHERE price >= 150000
ORDER BY price DESC;

Q43 · 모범답안

DISTINCT는 조회 결과의 중복 값을 제거합니다. GROUP BY는 동일한 값을 기준으로 Row를 그룹화하며 COUNT(), AVG(), SUM() 등의 집계함수와 함께 그룹별 통계를 계산할 때 주로 사용합니다.

Q44 · 정답

SELECT
    product_name,
    price
FROM products
WHERE price >= 100000;

Q45 · 정답

SELECT
    product_name,
    review_count
FROM products
ORDER BY review_count DESC
LIMIT 10;

Q46 · 정답

SELECT DISTINCT
    brand_name
FROM products;

Q47 · 정답

SELECT
    brand_name,
    COUNT(*) AS product_count
FROM products
GROUP BY brand_name
ORDER BY product_count DESC;

Q48 · 정답

GROUP BY와 ORDER BY의 작성 순서가 잘못되었습니다.

SELECT
    brand_name,
    AVG(price) AS avg_price
FROM products
WHERE price >= 100000
GROUP BY brand_name
ORDER BY avg_price DESC;
