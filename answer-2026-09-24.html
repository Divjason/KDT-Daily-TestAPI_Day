01. 객관식 정답 · Q1 ~ Q15

Q01 정답 ②

WHERE는 특정 조건을 만족하는 Row를 선택할 때 사용합니다.

WHERE → 어떤 데이터를 가져올 것인지 조건을 지정
Q02 정답 ②

결과는 서울, 부산, 대전입니다.

DISTINCT는 조회 결과에서 중복 값을 제거합니다.

Q03 정답 ②

DESC = Descending = 내림차순입니다.

따라서 가격이 높은 값부터 출력됩니다.

Q04 정답 ①

정답은 스마트워치, 러닝화입니다.

WHERE → 10만원 이상 필터링
ORDER BY DESC → 높은 가격부터 정렬
LIMIT 2 → 상위 2개만 출력
Q05 정답 ① 
SELECT AVG(price)
FROM products
WHERE category = '디지털';

AVG()는 Average, 즉 평균을 계산하는 집계함수입니다.

Q06 정답 ②

카테고리별 상품 개수를 계산합니다.

GROUP BY category → 카테고리별 그룹 생성
COUNT(*) → 각 그룹의 Row 개수 계산
Q07 정답 ②

order_count는 고객별 주문 Row 수를 의미합니다.

Q08 정답 ②

WHERE는 일반적으로 그룹화 이전 Row를 필터링합니다.

HAVING은 GROUP BY 이후 그룹화된 결과에 조건을 적용합니다.

Q09 정답 ②

JOIN은 서로 관련된 여러 Table의 데이터를 연결하여 조회할 때 사용합니다.

Q10 정답 ②

ON은 두 Table을 어떤 Column 관계로 연결할 것인지 지정합니다. 

ON c.customer_id
 = o.customer_id
Q11 정답 ③

김민지의 customer_id는 1이며, orders에 해당 고객의 주문이 2건 존재합니다.

따라서 2 Row가 출력됩니다.

Q12 정답 ④

필요한 관계는 다음과 같습니다.

customers → orders → products

customers와 products 사이를 orders가 연결합니다.

Q13 정답 ②

Subquery = 서브쿼리란 하나의 SQL 내부에 포함된 또 다른 Query를 의미합니다.

Q14 정답 ②

전체 상품의 평균 가격을 먼저 계산한 뒤, 그 평균보다 가격이 높은 상품을 조회합니다. 

WHERE price > (
    SELECT AVG(price)
    FROM products
)
Q15 정답 ②

내부 Subquery는 먼저 quantity가 2 이상인 주문의 product_id를 조회합니다. 

SELECT product_id
FROM orders
WHERE quantity >= 2;

02. 주관식 모범답안 · Q16 ~ Q20

Q16 WHERE + ORDER BY 
SELECT
    product_name,
    price
FROM products
WHERE price >= 100000
ORDER BY price DESC;
① products에서 조회 → ② 100,000원 이상 필터링 → ③ 가격 내림차순 정렬
Q17 GROUP BY 
SELECT
    category,
    COUNT(*) AS product_count
FROM products
GROUP BY category;

같은 category를 하나의 그룹으로 묶고 각 그룹의 상품 개수를 계산합니다.

Q18 2 Table JOIN 
SELECT
    c.customer_name,
    o.order_id
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id;
customers.customer_id ↔ orders.customer_id
Q19 3 Table JOIN 
SELECT
    c.customer_name,
    p.product_name,
    o.quantity
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id
JOIN products AS p
    ON o.product_id = p.product_id;
customers → orders → products

이 문제에서 핵심은 orders가 customers와 products를 연결하는 중간 Table이라는 점입니다.

Q20 Final Subquery Mission 
SELECT
    product_name,
    price
FROM products
WHERE price > (
    SELECT AVG(price)
    FROM products
)
ORDER BY price DESC;

내부 Query가 먼저 전체 상품의 평균 가격을 계산합니다.

Subquery → 평균 가격 계산

Main Query → 평균보다 비싼 상품 선택

ORDER BY → 가격이 높은 순서로 정렬
9/24 핵심 복습

SELECT / FROM → 데이터를 조회한다.
WHERE → Row에 조건을 적용한다.
GROUP BY → 같은 값을 기준으로 그룹화한다.
HAVING → 그룹화된 결과에 조건을 적용한다.
ORDER BY → 결과를 정렬한다.
LIMIT → 출력 Row 수를 제한한다.
JOIN → 서로 관련된 Table을 연결한다.
Subquery → Query 안에서 또 다른 Query의 결과를 활용한다.
