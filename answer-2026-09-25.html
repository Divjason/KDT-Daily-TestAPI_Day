02. 주관식 모범답안 · Q16 ~ Q20

Q162 Table JOIN 
SELECT
    c.customer_name,
    o.order_id,
    o.order_date
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id;
Q173 Table JOIN 
SELECT
    c.customer_name,
    p.product_name,
    o.quantity
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id
JOIN products AS p
    ON o.product_id = p.product_id;
customers → orders → products
Q18LEFT JOIN + IS NULL 
SELECT
    c.customer_name
FROM customers AS c
LEFT JOIN orders AS o
    ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;

결과: 윤지수

Q19JOIN + GROUP BY 
SELECT
    c.customer_name,
    COUNT(*) AS order_count
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id
GROUP BY
    c.customer_id,
    c.customer_name
ORDER BY
    order_count DESC;
Q20JOIN + Subquery 
SELECT
    c.customer_name,
    p.product_name,
    p.price
FROM customers AS c
JOIN orders AS o
    ON c.customer_id = o.customer_id
JOIN products AS p
    ON o.product_id = p.product_id
WHERE p.price > (
    SELECT AVG(price)
    FROM products
)
ORDER BY p.price DESC;
① Subquery로 평균 가격 계산 → ② 3 Table JOIN → ③ 평균보다 비싼 상품 필터링 → ④ 가격 내림차순 정렬
9/25 핵심 복습

JOIN → 관련 Table 연결
ON → 연결 조건
INNER JOIN → 양쪽에서 일치하는 Row
LEFT JOIN → 왼쪽 Table 유지
LEFT JOIN + IS NULL → 미매칭 데이터 탐색
GROUP BY + COUNT(*) → 그룹별 건수 집계
Subquery → 내부 Query 결과를 Main Query에서 활용
IN → 여러 반환값 중 하나와 일치하는지 확인
